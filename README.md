# Без воды

PWA для зала и питания: адаптивный расход по факту веса, программа с
автопрогрессией и подводящими подходами, 206 видео техники, русская база
еды (246 продуктов, 192 блюда), голосовой ввод, замеры и состав тела,
анализы крови, журнал препаратов с ценой за грамм действующего вещества.

**Данные о здоровье шифруются на устройстве (E2EE-vault).** В облако уходит
только зашифрованный бэкап — и только если пользователь включил синхронизацию.

Витрина: `/promo/about.html` (короткий адрес `/about`).
Принципы и журнал отказов: [PRINCIPLES.md](PRINCIPLES.md).
Рабочая доска: [NEXT.md](NEXT.md) · План: [BUSINESS_PLAN.md](BUSINESS_PLAN.md) · Рынок: [STRATEGY.md](STRATEGY.md).

## Стек
Ванильный JS, ни одной рантайм-зависимости.

- `index.html` — приложение целиком
- `sw.js` — service worker: офлайн-кэш, веб-пуши
- `api/` — серверные функции Vercel: ИИ-прокси с лимитами, отправка пушей (RFC 8291/8292 на `node:crypto`)
- `supabase/` — журнал применённых миграций (общий каталог, RLS, аналитика, пуши)
- `promo/` — лендинг, студия материалов, ролик для сторис, заготовки постов
- `tests/smoke.js` — тест-гейт (он же buildCommand), `tests/build.js` — сборка `dist/`

## Деплой
Push в `main` → Vercel: `node tests/smoke.js && node tests/build.js`.
Красный тест — деплоя нет. Конвенция версии: бамп `APP_VER` в `index.html`
и `C` в `sw.js` в каждом релизе.

## Внешние сервисы
- **Supabase** — Postgres/Auth/Storage: общий каталог еды, зашифрованные бэкапы,
  аналитика без слежки (write-only), пуш-подписки. В клиенте только publishable-ключ, всё под RLS.
- **Open Food Facts** — база продуктов по штрихкоду, без ключа.
- **Anthropic API** — ИИ-функции. Два пути: свой ключ пользователя (хранится
  только на его устройстве, запросы напрямую) или прокси `api/ai.js` на ключе
  владельца — с дневными и месячными лимитами и маршрутизацией по моделям.

## Что сознательно НЕ сделано
- **Разбор техники по видео** — технология не готова, ложные вердикты опасны в силовых.
- **Автозаполнение корзины магазинов** — публичного API корзины покупателя не существует.
- **Программа по фото** — дней, инвентаря, стажа и травм в пикселях нет.
- **Дозировки и протоколы AAS** — журнал приёма есть, консультирования не будет.

## Данные
Экспорт/импорт JSON во вкладке «Коуч». Бэкап — раз в месяц.
Очистка данных браузера стирает всё.
