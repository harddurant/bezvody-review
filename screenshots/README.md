# Скриншоты v679 на синтетических данных

Сняты 03.10.2026 в headless Chromium (390×844, масштаб 2) скриптом
`tools/screenshots_synthetic.js` по этой публичной копии. Профиль браузера
свежий; реальных данных нет. Продовая база не затрагивалась: ключ Supabase
в копии замаскирован, а `/sb`, `/api`, `/media` на локальном сервере
отвечают 404 — поэтому синхронизация, каталог, ИИ и видео здесь
недоступны так же, как у человека без сети или без аккаунта.

Порядок съёмки:

1. `01`–`06` — первый запуск: ворота, знакомство (пол, возраст, цель,
   итог «Программа собрана»), первый экран «Зала».
2. `07`–`10` — пустые состояния сразу после знакомства (простой режим
   включается автоматически).
3. Затем в базу браузера записана синтетическая история функциями самого
   приложения: 28 дней веса, 7 дней еды по 3–4 записи, 14 дней шагов,
   три тренировки по 5 упражнений первого дня программы. После
   перезагрузки приложение само переключилось в полный режим.
4. `11`–`17` — «Еда», поиск, ручной продукт, меню скана, поиск в Open
   Food Facts в состоянии загрузки (запрос подвешен) и ошибки (запрос
   оборван, как Safari: «Load failed»).
5. `18`–`26` — «Зал»: сегодня (по календарю синтетики — день отдыха),
   прошедшая тренировка с подходами, вкладка «Программа», лист сборки
   программы, каталог, карточка упражнения, «Закрыть тренировку».
6. `27`–`31` — «Тело» и «Здоровье».
7. `32`–`35` — «Коуч» и чат тренера. `35`: попытка отправить сообщение
   без своего ключа Anthropic и без бета-доступа — приложение уводит в
   настройки ключа.
8. `36`–`42` — настройки: корень, профиль, данные и облако, ключ ИИ,
   подписка с ценами, напоминания, лист входа.

Особенности, которые стоит знать при просмотре:

- В `20` заголовок дня «Отдых» при наличии подходов: синтетические
  тренировки записаны на календарные дни, не совпадающие с днями
  программы. Это артефакт синтетики, а не обязательно баг.
- Часть шагов скрипта вернула служебную ошибку CDP «Promise was
  collected» (не ошибка приложения); на каждом кадре проверено, что
  показан нужный экран.
- Экран оплаты как таковой не существует: есть только раздел подписки с
  ценами (`38`, `40`), продажи выключены флагом `SALES_ON=false`.
