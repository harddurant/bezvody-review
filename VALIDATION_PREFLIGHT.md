- Сильная неделя 2 без продолжения в тишине (R7).
- Больше половины подходящих по профилю отказываются на скрининге
  «тренироваться по программе приложения» (план §1.3): решения с головы
  снимать не нужно.
- На интервью ни один не называет потерей связку или «решение за меня»,
  а описывает прежний способ (тетрадь, Hevy, FatSecret) как достаточный.

### Что является проблемой текущей реализации, а не гипотезы

- Провалы входа: регистрация, синхронизация, установка. Считаются в
  метрике «Вход» (R1).
- Р-1…Р-4: программа без дней недели, жёлтая кнопка в обход знакомства,
  непроверенная регистрация, автоматическое первое взвешивание.
- Стартовые веса по нормативам, которые не совпали с реальными.
- Адаптивная цель, которая за 14 дней не успела пересчитаться (план §2.2).
- Нет итога прогресса после тренировки (план §2.2).
- Баги и ошибки каталога или OFF.

Такие проблемы записываются, но вердикт по ним не меняется. Исключения:
- проблема не дала пройти вход ≥ 20 % пришедших — тест без вердикта, перезапуск после решения владельца;
- проблема — то самое «одно звено» в ITERATE.

## 4. FINAL GO / NO-GO

Блокеров безопасности нет. Путь входа проходится, кроме непроверенной
регистрации — она проверяется первой же встречей дня 0 по R1. Поправки
