# Промо-материалы

Всё делается внутри проекта: ни сторонних приложений, ни подписок, ни загрузки
твоих картинок на чужие серверы. Единственное «внешнее» — встроенная в телефон
запись экрана, и то только для ролика.

- **`about.html`** — лендинг «что это и для кого»; короткий адрес `/about`. Сюда вести ссылки из канала.
- **`studio.html`** — посты для канала, скриншоты для магазина, аватар. Скачивает PNG. Короткий адрес `/studio`.
- **`reel.html`** — вертикальный ролик 9:16 для сторис (записывается с экрана). Короткий адрес `/reel`.
- **`posts.md`** — восемь готовых постов на первый месяц канала.

---

## `studio.html` — картинки

Открой файл в браузере. Четыре вкладки:

| Вкладка | Что делает | Размер |
|---|---|---|
| Пост для канала | Заголовок + выделенная строка + подпись, на фирменном фоне | 1080×1350 · 1080×1080 · 1080×1920 |
| Скриншот для магазина | Твой скриншот в рамке телефона + подпись сверху | 1080×1920 |
| Аватар и обложка | Знак, опционально с названием | 640×640 |
| Ролик | Ссылка на `reel.html` | — |

Всё рисуется на `<canvas>` прямо в браузере и скачивается кнопкой. Файл,
который ты перетаскиваешь в «Скриншот для магазина», никуда не отправляется —
он читается локально и остаётся в браузере.

Для магазина нужно минимум 2–3 скриншота. Делай **по одному тезису на каждый**:
адаптивный расход, видео техники, русская еда. Их листают как рекламу, а не
читают как документацию.


## `reel.html` — вертикальный ролик для сторис

Это не видеофайл, а анимированная страница в формате 9:16, которую нужно
**записать с экрана**. Так сделано специально: текст, цифры и порядок сцен
меняются в одну строчку, без перерисовки видео.

### Как записать

1. Открой `promo/reel.html` в браузере.
2. Нажми **H** — прячется служебная полоска внизу.
3. Нажми **Пробел** — ролик начинается сначала.
4. Запиши:
   - **macOS:** `Cmd+Shift+5` → «Записать выбранную область» → выдели кадр;
   - **Windows:** «Игровая панель» `Win+G` или ScreenToGif;
   - **Телефон:** открой файл в браузере телефона и включи запись экрана —
     кадр сам подстроится под экран, обрезать не придётся. Это самый простой путь.
5. Ролик зациклен. Останови запись, когда пройдёт один круг (≈27 секунд).

### Что поменять перед публикацией

В начале блока `<script>`:

- `LINK` — адрес приложения, который показывается в конце;
- `T` — длительность каждой сцены в миллисекундах, если хочется быстрее или медленнее.

Тексты сцен — прямо в HTML, каждая сцена это `<section class="sc">`.

### Где это использовать

- Instagram Reels / Stories — 9:16 родной формат;
- Telegram: сторис, статус, пост в канале;
- первый закреплённый пост в канале.

### Чего здесь нет

Звука. Ролик рассчитан на просмотр без звука — так смотрят сторис в
большинстве случаев. Если нужна музыка, накладывай при монтаже уже
поверх записи.
