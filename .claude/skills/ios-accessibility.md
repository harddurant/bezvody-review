# Доступность и области касания по Apple HIG — жёсткие числа для «Без воды»

Применять при каждой правке интерфейса. Числа — из HIG (`accessibility`,
`layout`, `buttons`, `voiceover`, `typography`, `color`) и WCAG 2.2, на который
HIG ссылается по контрасту. В `index.html` действуют токены `--tap` (44 px) и
шкала кеглей v580 — ниже них не опускаться.

## 1. Контраст (текст и значки к фону)

| Что | Минимум | Норма проекта |
|---|---|---|
| Обычный текст (< 24 px / < 19 px bold) | **4.5 : 1** | подписи `rgba(255,255,255,.5)` на `#000` ≈ 5.3 : 1 ✓; на карточке `#1C1C1E` ≈ 4.7 : 1 ✓ — ниже .5 не опускать |
| Крупный текст (≥ 24 px или ≥ 19 px bold) и значки/границы контролов | **3 : 1** | шеврон `rgba(255,255,255,.3)` ≈ 3.2 : 1 — предел; тоньше нельзя |
| Акцент (лайм `#D8FF00` на чёрном) | — | 18 : 1; чёрный текст на лайме 17 : 1 ✓; лайм на белом (светлая тема) — 1.2 : 1 ✗, поэтому там `--ac:#4f7000` |
| Ошибка/предупреждение | 4.5 : 1 | `#FF9F0A` на `#000` 9.9 : 1; `#B35E00` на `#fff` 4.6 : 1 ✓ |

Правила: цвет никогда не единственный носитель смысла (рядом слово, форма или
значок); темы дают **свои** значения переменных, а не один цвет на обе;
`prefers-contrast: more` — усилить подписи до `.72`.

## 2. Области касания (Hit Targets)

| Плотность / контекст | Минимум по HIG | Норма проекта |
|---|---|---|
| Любой контрол | **44 × 44 pt** | `--tap` (44) — кнопки, чекбоксы `.wcheck`, шевроны листов |
| Одна рука, в движении (зал: гантель в руке, между подходами) | 48–54 pt | строки-переходы 48–52, «Начать тренировку» 54, кнопки подвала 50 |
| Плотные ряды (сегменты, чипы) | 44 по высоте, ширина по тексту, зазор ≥ 8 pt | `.seg` кнопки 44, чипы ≥ 44 в рядах вариантов |
| Визуально маленький элемент (36-px кнопка, 28-px переключатель) | зона нажатия всё равно 44 | `::before{inset:-4px}` (кнопка «Пересчитать» 36 + 8 = 44), `.wfold` 28 внутри ячейки 44 |
| Зазор между соседними целями | ≥ 8 pt | ряды тегов и пилюль — `gap:8px` |
| Зона «большого пальца» (нижняя треть экрана) | главное действие здесь | «Записать еду», таймер отдыха, nav — внизу |

Никогда: цель < 44 в любой размерности, две цели вплотную, действие только по
долгому нажатию без видимой альтернативы.

## 3. VoiceOver и скринридеры

- Каждая иконка-кнопка — `aria-label` глаголом («Закрыть», «Записать подход»,
  «Свернуть записанные подходы»); декоративные `svg` — `aria-hidden="true"`.
- Скрытый текст для читалки — класс `.sr` (в проекте: `#v-train .sr`), паттерн
  `position:absolute;width:1px;height:1px;overflow:hidden;clip:rect(0 0 0 0);white-space:nowrap`.
  Не `display:none` и не `visibility:hidden` — их читалка не видит.
- Состояние — атрибутами, не цветом: `aria-pressed` у переключателей,
  `aria-expanded` у раскрывашек (нативный `<details>` даёт сам), `aria-disabled`
  вместо `disabled` там, где нужен фокус для объяснения.
- Порядок чтения = порядок DOM; визуальные перестановки — только `order`/флекс
  там, где смысл не зависит от порядка (крестик листа: `order:-1` допустим,
  заголовок читается первым).
- Живые изменения (таймер отдыха, тост) — `aria-live="polite"`; сигнал конца
  отдыха — `assertive`.
- Модальные листы: фокус внутрь при открытии, возврат на кнопку-источник при
  закрытии; фон — `inert` (или `aria-hidden`) пока лист открыт.
- Dynamic Type: кегли только через шкалу `--fs0…--fs5`, `line-height` через
  `--lh*`; ничего в `px` руками, чтобы масштаб системы переносил всё разом.
- Reduced Motion: `prefers-reduced-motion: reduce` — убрать масштаб и смещение,
  оставить `opacity` ≤ 120 мс (см. `apple-springs.md`).

## 4. Проверка (что меряет гейт и что руками)
- Гейт: `min-height:44px` у кнопок/раскрывашек, `--tap`, шкала кеглей и сетка,
  один лаймовый акцент, крестик на ведущем краю, `.sr` в строке готовности.
- Руками на iPhone: VoiceOver по «Залу» от заголовка до «Спросить тренера» —
  каждая кнопка называет действие; Настройки → Дисплей → крупный текст — ничего
  не обрезано; «Уменьшить движение» — листы появляются без пролёта.
