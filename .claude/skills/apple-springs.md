# Физика пружин Apple — константы для CSS/JS (чистый markdown, без кода-исполнения)

Применять при любой анимации в `index.html`: движение листов, кнопок, кружков
записи подхода, переходов. Источник констант: документированные API Apple
(SwiftUI `Spring`, UIKit `UISpringTimingParameters`), пересчёт в CSS — наш.
Где число — аппроксимация, так и написано.

## 0. Как Apple задаёт пружину

SwiftUI и UIKit описывают пружину двумя числами, а не жёсткостью:
- **response** (с) — период: сколько занял бы один полный цикл без затухания;
- **dampingFraction** — доля критического затухания: 1.0 — без перелёта,
  <1 — перелёт (bounce), >1 — вязко.

Пересчёт в физику (mass = 1):
- `stiffness = (2π / response)²`
- `damping = 4π · dampingFraction / response`

| Пресет Apple (iOS 17+, документирован) | response | dampingFraction | stiffness | damping |
|---|---|---|---|---|
| `.smooth` | 0.50 | 1.00 | 158 | 25.1 |
| `.snappy` | 0.50 | 0.85 | 158 | 21.4 |
| `.bouncy` | 0.50 | 0.70 | 158 | 17.6 |
| `.spring()` по умолчанию | 0.55 | 0.825 | 130 | 18.8 |
| UIKit `UISpringTimingParameters` по умолчанию | ≈0.55 | 1.0 (dampingRatio) | 130 | 22.8 |

Длительность «на глаз» ≈ 1.2 × response при damping ≥ 0.8 (движение
визуально заканчивается раньше математического).

## 1. Три стандарта для «Без воды»

### 1.1 iOS Standard Pop / Push — упругий отклик (появление листа, переход)
- Пружина: **response 0.45 · dampingFraction 0.85** (между `.snappy` и `.spring()`),
  stiffness 195 · damping 23.7 · mass 1.
- CSS-аппроксимация без пружины: `cubic-bezier(0.32, 0.72, 0, 1)` · 420 мс
  (кривая быстро набирает, мягко доезжает, без перелёта — то, что глаз читает как
  «системный push»).
- Честная пружина в CSS: `linear(0, 0.108 5.4%, 0.376 12.2%, 0.653 18.5%, 0.83 24.3%, 0.93 30.1%, 0.98 36.6%, 1.002 44.3%, 1 100%)` · 480 мс.
- Свойства: только `transform` и `opacity`. В проекте: `@keyframes up` листа
  (`.sheet .in`) и возврат после незавершённого свайпа (`sheetSwipe`).

### 1.2 iOS Sheet Dismiss — плавное затухание шторки вниз
- Пружина: **response 0.40 · dampingFraction 1.0** (критическое затухание — шторка
  не «отскакивает» от низа), stiffness 247 · damping 31.4 · mass 1.
- CSS: `cubic-bezier(0.4, 0, 1, 1)` для ухода по тапу (ease-in, 220–260 мс);
  для ухода после свайпа — стартовая скорость пальца важнее кривой: длительность
  = `оставшийся путь / скорость`, зажатая в 120–320 мс, кривая `linear` первые
  20 % и `ease-out` дальше (`cubic-bezier(0.2, 0.8, 0.3, 1)`).
- Одновременно фон-подложка гаснет линейно за ту же длительность.
- В проекте: `.sheet.closing .in{animation:down .18s var(--ez)}` — по замерам 180 мс
  короче системных 260; допустимо поднять до 240 мс только вместе с замком фона
  (`shlockSync` держит `.closing`).

### 1.3 iOS Spring Bounce — микровзрыв для кружка выполнения (чекбокс подхода)
- Пружина: **response 0.30 · dampingFraction 0.55**, stiffness 439 · damping 23.0 ·
  mass 1 — один заметный перелёт и быстрый покой.
- CSS-аппроксимация: `cubic-bezier(0.34, 1.56, 0.64, 1)` · 260 мс (перелёт до
  ~1.12 масштаба).
- Честная пружина: `linear(0, 0.2 3.5%, 0.75 10%, 1.12 17%, 1.18 21%, 1.06 30%, 0.98 40%, 1.01 52%, 1 100%)` · 320 мс.
- Схема: `scale(1) → scale(0.86)` на `:active` (12 мс, без анимации) →
  отпустил → пружина к `scale(1)` с перелётом; галочка проявляется `opacity 0→1`
  за первые 40 % пути. Тактильный отклик — `navigator.vibrate(10)` там, где есть.
- В проекте: `.wcheck.on{animation:ckPop .16s var(--ezb)}` — заменить кривую
  `--ezb` на кривую выше, длительность 260 мс.

## 2. Правила применения
- Одна кривая на один класс движения: появление — 1.1, уход — 1.2, подтверждение —
  1.3. Не смешивать «по вкусу».
- Прерываемость: новая анимация стартует с текущего значения, а не с начала
  (CSS-переходы это делают сами; `@keyframes` — нет, для прерываемых жестов
  использовать transition).
- `prefers-reduced-motion: reduce` → все три сводятся к `opacity` 120 мс без
  масштаба и смещения.
- Длительности >500 мс на телефоне читаются как «зависло»; <120 мс — как «мигнуло».
- Никаких `top/left/width/height` в анимациях — только `transform`/`opacity`
  (композитор, без reflow; см. CRAFT.md).
