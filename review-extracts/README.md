# Извлечения для чтения

`index.html` (3 МБ, 31 007 строк) и `tests/smoke.js` (1,5 МБ) слишком велики для просмотра на GitHub и для многих веб-инструментов. Здесь они нарезаны на куски с номерами строк оригинала. Оригиналы лежат в корне копии без изменений (кроме маскировки, описанной в `PUBLIC_COPY_NOTES.md`).

Грубая карта `index.html`: строки 1–14 — `<head>`; 15–2651 — CSS; 2652–4599 — разметка (вкладки, листы, настройки); 4600–4631 — ранний страж ошибок; 4632–31007 — один большой `<script>`: хранилище, навигация, справочники упражнений и продуктов, генератор программ, рендер вкладок, ИИ, синхронизация, запуск.

- [FUNCTION_INDEX.md](FUNCTION_INDEX.md) — функции верхнего уровня с номерами строк.
