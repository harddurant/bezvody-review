# SPEC.md — реестр обещаний

Заведён 02.09 по вопросу владельца: «я не понимаю, а так ли та или иная
функция должна работать». Пока это нигде не записано, дыру нельзя найти —
её можно только случайно заметить, строя соседнее. Поэтому здесь одна
строка на каждую функцию: **что она обязана делать**. Не как устроена —
что обещает человеку.

**Как этим пользоваться.** Открыл экран, показалось странным — нашёл строку
здесь. Совпало с обещанием — так задумано, спорь с обещанием. Не совпало —
это баг, и его видно без меня.

**Как это не сгниёт.** `node tests/audit.js` обходит приложение и ругается
на лист, которого здесь нет: новая функция не может появиться молча.
Колонка «стережёт» — есть ли правило в гейте, которое поймает поломку
этого обещания. Пустая колонка честно значит «поломку заметит только
человек».

**Оговорка о колонке «стережёт».** Она считает правила, которые называют
лист по имени. Полевые прогоны (`field.js`, `kitchen.js`) проходят сценарий
целиком и задевают многое, не называя. То есть «—» значит «отдельного
правила нет», а не «не проверяется вовсе».

## Функции, которых нет в простом режиме

Замер обхода 02.09: **30 блоков** живут только в полном режиме. Из них
шесть — это чтиво (честно про MEV/MAV/MRV, оговорка про ACWR, зачем мерить
рычаги, почему приложения врут про калории, куриная грудка, «читать —
коротко и без воды»), а несколько блоков — одна функция в трёх частях
(фото = галерея + сравнение + съёмка; сон = карточка + график + история).

не знает об их существовании: ровно так «отсутствовало» сравнение фото —
месяц в очереди на постройку, хотя оно было написано и спрятано.

## Правила этого файла

1. **Одна строка на функцию.** Не описание устройства — обещание человеку.
2. **Новая функция — новая строка сразу**, а не «потом опишем». Обход
   печатает лист без строки здесь как находку.
3. **Обещание меняется решением, а не правкой кода.** Если код разошёлся
   с этой строкой — сначала решаем, кто прав.
4. **Пустая колонка «стережёт» — не грех, а цена.** Она честно говорит,
   где поломку заметит только живой человек.
